# A-to-Z Blockchain & ONXC Student Glossary

Plain-language definitions for every term used across **OENEXA**, **ONXC**, and the interactive [**Visual Learning Studio**](./visual-lab/index.html).

- **Address (`32 bytes` / `64 hex chars`)**: Your public receiving account ID on OENEXA, calculated as `SHA-3-256(PublicKey)`. Accepted as bare hex, `0x...`, or `onxc...` (and 20-byte hex inputs right-aligned cleanly).
- **Argon2id**: A memory-hard key derivation function (`64 MiB` RAM, `3` rounds, `4` threads per guess) that turns your password into an `AES-256` key so thieves cannot brute-force `keystore.json`.
- **Avalanche Effect**: Property of `SHA-3-256` where changing 1 bit of input scrambles ~50% of all 256 output bits unpredictably.
- **Base Fee (`BaseFee`)**: Automatic per-gas fee (starts at `10 nano-ONXC/gas`, minimum `1`) that adjusts up or down by at most `±12.5%` depending on whether the parent block exceeded `50%` of `BlockGasLimit`. **Every Base Fee is permanently burned.**
- **BFT (Byzantine Fault Tolerance)**: Consensus protocol ensuring all honest validators agree on the exact same finalized block even if up to almost `1/3` (`f`) of validator voting power crashes or acts dishonestly.
- **Block**: Numbered batch of up to `10,000` verified transactions plus header (`Height`, `PrevHash`, `TxRoot`, `StateRoot`, `BaseFee`, `GasUsed`, proposer `Signature`). Created every `2` seconds.
- **Commitment (`Note Commitment`)**: One-way `SHA-3-256` hash (`"OENEXA_NOTE_CM"`) hiding a Shielded Pool note's value and recipient behind a 256-bit random blinding factor (`Rcm`).
- **Consensus**: Four-step voting loop (`StepPropose` $\to$ `StepPrevote` $\to$ `StepPrecommit` $\to$ `StepCommit`) achieving instant finality.
- **Delegation**: Locking your ONXC (minimum `1,000,000 nano-ONXC` = `0.001 ONXC`) behind an active validator to earn a pro-rata share of rewards minus validator commission (default `500 bps = 5%`).
- **Dual-Pool Architecture**: OENEXA's native design pairing a public **Transparent Pool** (Sparse Merkle Trie) with a private **Shielded Pool** (notes + nullifiers), enforced by the Turnstile.
- **Equivocation**: Cheating offense where a validator signs two conflicting votes at the same `(height, round)` — punished by **`10%` stake slashing** (`val.Stake / 10`).
- **Finality**: Moment a transaction can never be reversed. OENEXA grants **instant 1-block finality (~2 seconds)** with zero forks.
- **Gas**: Measure of compute work (`21` transfer, `50` shield, `100` unshield, `150` shielded transfer, `500` contract call, `5,000` contract deploy; max `500,000,000` per block).
- **Genesis Block (Height `0`)**: Initial block allocating `10,000,000 ONXC` (`5M` Treasury, `3M` Liquidity, `2M` Staking Bootstrap).
- **Halving**: Cutting the validator `BlockReward` in half (`>> 1`) every `1,000,000` blocks (starting at `45 ONXC`), proving total supply never exceeds `100,000,000 ONXC`.
- **Hash (`SHA-3-256` / `Keccak-f[1600]`)**: FIPS 202 Sponge hash (`Rate = 1,088 bits`, `Capacity = 512 bits`, `24` rounds of `Theta, Rho, Pi, Chi, Iota`) turning any input into a one-way `32`-byte fingerprint.
- **Keystore (`keystore.json`)**: Your encrypted wallet file on disk (`0o600`) locked with `Argon2id` + `AES-256-GCM` (`CTR` + `GHASH` tag).
- **Layer-1 (L1) / Layer-2 (L2)**: L1 (`OENEXA`) is the base settlement blockchain; L2 (`Rollup Sequencer`) executes batches off-chain and settles compressed proofs to L1.
- **M-LWE & M-SIS**: Hard post-quantum Euclidean lattice problems (*Module Learning With Errors* and *Module Short Integer Solution*) over polynomial ring $R_q = \mathbb{Z}_q[X]/(X^{256}+1)$ underlying `ML-DSA-65` and `ML-KEM-768`.
- **Mempool**: Priority Max-Heap (`DefaultMaxSize = 100,000`, `MaxSenderQueueLen = 10,000`) sorting waiting valid transactions by highest `GasPrice` and earliest `Timestamp`.
- **ML-DSA-65 (FIPS 204)**: Post-quantum lattice digital signature algorithm (`1,952 B` pubKey, `4,032 B` privKey, `3,309 B` signature) resistant to quantum computers.
- **ML-KEM-768 (FIPS 203)**: Post-quantum key encapsulation used to encrypt private Shielded Pool note payloads.
- **Multisig (M-of-N)**: Smart contract vault requiring `M` distinct `ML-DSA-65` owner signatures out of `N` registered keys before releasing ONXC.
- **nano-ONXC**: Atomic integer coin unit ($1\text{ ONXC} = 1,000,000,000\text{ nano-ONXC}$). Prevents floating-point rounding discrepancies.
- **Nonce**: Sequential per-sender transaction counter (`0, 1, 2, ...`) stopping replay attacks.
- **Nullifier**: Unique deterministic tag (`"OENEXA_NULLIFIER"`) published once inside `NullifierSet` when spending a shielded note, blocking double-spends privately.
- **OENEXA**: Sovereign, post-quantum Layer-1 blockchain platform (`ChainID = 1`, `ProtocolVersion = 1`).
- **OenexaVM**: Pure-Go `wazero` WebAssembly smart contract sandbox featuring module caching, atomic rollback on out-of-gas, and 8 `env.oen_*` host functions.
- **ONXC**: **Open Network for the Next Generation Coin** — native currency of OENEXA (`100,000,000` hard cap, `9` decimals).
- **Oracle**: Off-chain reporter submitting signed prices for sovereign `ONXC` pairs (`ONXC-USD`, etc.) aggregated by Byzantine-resistant median.
- **Priority Tip**: Optional extra fee per gas above `BaseFee` paid directly to the block validator for faster queue placement.
- **Rejection Sampling (Fiat-Shamir with Aborts)**: Loop inside `ML-DSA-65` signing that discards any candidate signature `z = y + c*s1` whose size could reveal statistical information about the secret vector `s1`.
- **Rosetta API (v1.4.14)**: Universal exchange/custody REST API supporting air-gapped offline signing.
- **Slashing**: Removing `10%` of stake from a validator caught equivocating.
- **Sparse Merkle Trie (SMT)**: Fixed `256`-bit binary cryptographic tree mapping 32-byte addresses using bit paths + `zeroHash` sentinels for order-independent `StateRoot` and `~1 KB` proofs.
- **StateRoot**: Single 32-byte hash authenticating every balance and nonce in the world at that block height.
- **Turnstile**: Supply-conservation guard guaranteeing `TransparentSupply + ShieldedSupply == TotalSupply`.
- **Validator**: Staked node operator who builds blocks in round-robin order (`height % N`) and votes in BFT consensus.
- **Viewing Key**: Read-only key allowing selective auditing of shielded notes without spending authority.
